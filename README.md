# Walmart Customer Retention Analytics

Interactive Power BI Dashboard to analyze customer retention, churn rate, loyalty programs, promotional impact, store performance, and Customer Lifetime Value (CLV).

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Project Objectives
- Analyze customer churn and retention.
- Understand repeat customer behavior.
- Evaluate promotion and loyalty program performance.
- Analyze store and channel performance.
- Identify high-value and low-value customers.

## Dashboard Pages
1. Customer Retention & Churn
2. Loyalty & Promotion Impact
3. Store & Channel Insights
4. Customer Segmentation & CLV
5. Project Presentation
